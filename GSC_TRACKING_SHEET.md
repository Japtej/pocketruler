## GSC Coverage Status Codes to Watch

| Status | Meaning | Action |
|--------|---------|--------|
| **Valid** | Indexed & appearing in search | ✅ Good |
| **Crawled - currently not indexed** | Google crawled but chose not to index | Improve content quality, request indexing again |
| **Discovered - currently not indexed** | Google knows URL but hasn't crawled | Submit for indexing, check crawl budget |
| **Duplicate without user-selected canonical** | Canonical issue | Fix canonical tags |
| **Blocked by robots.txt** | robots.txt disallows | Fix robots.txt |
| **Redirect** | Page redirects | Ensure final URL is indexed |
